# factcheck — 전수 팩트체크 절차 · 이미지 차용 기준

> 설계문서(2026-07-21 spec §7-1·§7-2)에만 있던 절차를 런타임 참조로 승격한 정본이다.
> SKILL.md 게이트②·④export가 "전수" 선택 시 이 문서의 §A를, 게이트① 아웃라인의
> 이미지 배치 판정이 §B를 따른다.

## §A. 전수 팩트체크 (게이트② 승인 후, 변환 전 — 옵트인)

실행 여부는 게이트②에서 사용자가 확정한다 — ⓐ 전수(대외·상위 보고 권장, +수 분) /
ⓑ 경량(기본값 — `validate_hwpx.py numbers`가 초안 수치를 research와 문자열 대조, 에이전트
0개) / ⓒ 생략. ⓑ·ⓒ 선택 시 미검증 사실이 남을 수 있음을 인도 시 1줄 고지한다.

ⓐ 전수 선택 시 **초안을 쓴 컨텍스트와 분리된 독립 서브에이전트**가 "반박할 수 있는가"의
관점으로 검증한다:

1. **추적 검증** — 초안의 모든 수치·인용·고유명사·날짜를 `research/` 산출물(제공자료·위키
   인용·조사 결과)과 대조한다: 출처가 실재하고 값이 일치하는가. 표 셀→출처 매핑도 이때
   전수 확인한다.
2. **태깅 정합** — `[확정]` 표기 항목이 실제로 검증 가능한 원출처를 갖는지 확인한다.
   불충분하면 `[추정]` 강등을 제안한다.
3. **이미지 정합** — 차용 이미지의 캡션 출처가 `_manifest.jsonl`과 일치하는지, 이미지
   내용이 본문 주장과 정합하는지 확인한다(§B 차용 기준 위반도 이때 잡는다).
4. **외부 재검증 (선택적)** — 근거가 research 산출물에 없거나 의심스러운 **핵심 주장 한정**
   웹 재검색으로 교차확인한다. 전체 재조사가 아니다.

**산출**: `35_factcheck.md` — 항목별 판정표.

```
| 절 주소 | 항목(수치·인용·표 셀·이미지) | 출처(research/ 경로) | 판정 | 조치 |
|---|---|---|---|---|
| □2-ㅇ1 | "예산 3.2억" | fetched/pims/budget.md | 일치 | — |
| □3-ㅇ2 | "'25년 지적 4건" | (없음) | 출처 없음 | [추정] 강등 또는 삭제 |
```

판정은 **일치 / 불일치 / 출처 없음** 3종. 불합격 항목이 있으면 수정 후 **게이트② 간이
재확인**을 거친다(사실이 바뀌면 사용자가 다시 봐야 한다). 전 항목 합격 시에만 변환으로
진행한다. 발견된 오류 유형은 lessons에 `gate:"factcheck"`로 기록한다 — 반복되면 초안 작성
규칙으로 승격된다(SKILL.md §6 복리 훅).

## §B. 근거 이미지 차용 기준 (게이트① 배치 승인)

외부조사에서 수집한 이미지 중 **보고서의 근거·기초가 되는 것만** 본문에 차용한다 — 장식용
이미지는 쓰지 않는다.

- **차용 3조건**: ⓐ 본문 논지를 직접 지탱하는 근거(공식 통계 차트·제도 구조도 등)일 것,
  ⓑ 출처가 `_manifest.jsonl`에 실재할 것, ⓒ 규격이 **1페이지의 1/3 이내**(본문 폭 170mm ×
  높이 90mm — `check_image_size.py`로 판정)일 것. 초과 이미지는 축소해도 판독 가능하면
  축소, 아니면 차용을 포기하고 텍스트 요약 + 출처 각주로 대체한다.
- **배치 승인은 게이트①**: `10_outline.md`의 "이미지 배치" 절에 어떤 이미지가 어느 절에서
  어떤 논지의 근거인지, 규격 판정 결과와 함께 제시한다. 표 설계와 동일한 원칙 — 이미지는
  장식이 아니라 논지 구조물이다.
- **본문 표기**: md에는 이미지 마커로 위치만 지정하고, 캡션에 출처(발행기관·자료명·연도)를
  필수 병기한다. 저작권 유의 자료(유료·비공개)는 차용하지 않고 인용·요약으로 대체한다.
- **주입·검증은 변환 단계**: hwpx-recipe.md §3(이미지 규격 판정·주입) 절차를 따르고, 왕복
  QA에서 존재·위치를 확인한다. 규격 검증 실패 시 변환을 멈추고 보고한다.
