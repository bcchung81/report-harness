> 근거: `form/보고서/` 실보고서 34건 전수 분석 (2026-07-22, 병렬 3차 분석 교차 대조. 파싱 34/34 성공.
> 단 `250612_LG AI연구원 벤치마킹…hwp`는 내용물이 '챗GPT 심층리서치 일정' 문서와 중복 — 실질 33종).
> 표기: [철칙] = 3개 분석 모두 "전 파일 공통" 판정 / [관례] = 다수 파일 / [조건] = 문서 유형별 분화.
> 이 가이드는 스타일 셀프감사·회귀검사의 판정 기준이다. 기본 양식 문서와 실무 관례가 다르면 **실코퍼스 우선**.

## 0. 문서 유형 판별 (문체가 갈리는 최상위 분기)

| 유형 | 분량 | 구조 | 문체 |
|---|---|---|---|
| **단신 요약보고** (표준, 이 가이드의 기본값) | 1~3p | □ 절 구조 | 명사형 종결 개조식 |
| 표지+목차형 계획서 | 다p | 표지·목차 + 로마숫자 장(Ⅰ.) + ◇ 헤드라인 | 개조식 + 볼드 다용 |
| RFP·행정 서식 | 다p | 장·절 배너 표 + □ 라벨형 | "~하여야 함" 종결 |
| 붙임 회의록 | — | □ 절 재사용 | "~함/~답변함" 서술 허용, 3~4줄 허용 |

## 1. 제목·헤더

- [철칙] 문서 제목 = **명사구 + 문서유형 접미**: ~보고 / ~검토결과 / ~계획(안) / ~추진계획(안) / ~결과 보고 / ~방안 / ~개선(안). 미확정 문서는 **(안)**, 미확정 명칭은 **(가칭)**, 수신 명시는 괄호 "(원장님)".
- [철칙] 제목 바로 아래 발신 줄: `< '26. 3. 31.(화), 경영기획본부 AI디지털심화팀 >` — 꺾쇠 안 "축약연도. 월. 일.(요일), 본부 팀". **발신 줄은 일(日) 뒤 온점 후 요일 괄호**(본문 날짜는 온점 생략형 `'25. 6. 27(금)` 병존). 날짜는 **실제 보고일**(파일명 날짜와 다를 수 있음).
- [관례] 버전·상태 태그(v0.2, ★최종★)는 파일명 전용 — 문서 내 제목에 넣지 않는다.
- [관례] 고유 사업명은 겹낫표 「 」, 서비스·시스템명은 홑따옴표 ' '.

## 2. 계층형 구조

- [철칙] 위계: **□(절 제목 전용) → ㅇ(요지) → -(상세) → ※(단서·출처·예외) → ＊(용어 각주)**. 최대 4~5단.
  - □는 절 제목에만 쓰고 본문 서술에 쓰지 않는다.
  - ㅇ = 핵심 요지 1문장(그것만 읽어도 보고 완결). - = 방법·수치·부연. ※ = 조건·예외·후속 참조. ＊ = 용어 정의(문장 뒤 ＊ 표시 후 항목 하단 풀이).
  - ㅇ/○는 문서 단위로 하나만 택해 통일 (혼용 금지).
  - ☞(결론 유도)는 소수 관례 — 검토보고의 귀결 문장에만 선택적.
- [철칙] **괄호 리드**: ㅇ 선두에 "(키워드)" — 항목 성격어("(목적)", "(조사대상)") 또는 대상명("(GPU서버 구매)", "(호환성)"). **2음절 리드는 벌려쓰기**: "(목 적)", "(일 정)".
- [관례] 인라인 나열은 ①②③ 원문자. 절이 길면 □ 아래 `[1] [2]` 중간 섹션 허용.
- [철칙] 벌려쓰기(자간 정렬)는 2음절 어휘 공통 관례: 절 제목 "개 요", 표 헤더 "구 분"·"효 과", 붙임 "붙 임".

## 3. 서술량·줄바꿈 (사용자 핵심 규칙)

- [철칙] **한 항목 = 한 문장 = 2줄 이내.** ㅇ는 약 40~120자(1~2줄, 다수 관찰 40~90자), -는 40~90자(1~1.5줄). 문장 중간 강제 개행 금지(워드랩에 맡김).
- [철칙] 2줄 초과가 예상되면 **배출구**로 분리: 하위 -로 쪼개기 / ※ 1줄 단서 / ＊ 각주 / 표 전환. 본문을 3줄로 늘리는 선택지는 없다.
- [철칙] **나열 3개 초과 + 속성 2개 이상 → 표로 전환.**
- [관례] 문장은 연결어(~하여, ~통한, ~따라)로 한 문장에 압축하되 명사형 종결에서 끊는다. 두 문장으로 쪼개 항목 하나에 담지 않는다.
- 예: "ㅇ (목적) KCA 모든 부서의 AI도구 구독 현황을 파악하여 부서별 AI 격차를 해소하고 AI 활용 강화를 위한 환경 조성" (250408)

## 4. 종결어미·조사

- [철칙] **동작명사 종결이 표준**: ~구축·~추진·~지원·~마련·~제공·~실시·~수립·~확보·~검토·~조성. 상황별: ~필요(배경·건의 절), ~예정(계획), ~가능(검토 결과).
- [철칙] **"~함/~임/~음" 종결은 본문에서 쓰지 않는다** (코퍼스 34건 중 본문 출현 극소수). 예외: RFP("~하여야 함")와 붙임 회의록("~답변함")에만 허용.
- [철칙] 조사 생략 + 가운뎃점(·) 병렬 압축: "근거 소실·실적 누락·작성부담 해소". 단 관형 조사(~을 통한, ~를 위한, ~에 따라)는 유지.
- [관례] 주어(우리 기관·당 팀)는 생략. 기관 지칭 시 "KCA", "우리 원"(격식 문서), "본사/지방본부".

## 5. 표기법

- [철칙] 날짜: 아포스트로피 연도 축약 + 요일 괄호 — `'25. 6. 27(금)`, `'25.6월`(월 단위 붙여쓰기), 범위는 물결 `'26. 1. 13(화) ~ 1. 23(금)`, 연도만은 `'27년`.
- [철칙] 수치: 천 단위 콤마 `349,850,000원(VAT포함)`, 한국식 축약 `약 76백만원/년`·`11천원/월`, 배수 `3.5배`, 병기 `137명(23.7%)`, 변화 `10-15분 → 30초`, 근사 `약`.
- [관례] 산식 병기(제3자 재계산 가능): "6백만원 = (30만원/시간 × 4시간) × 5회".
- [관례] 외래 고유명사 원어 병기 + 상세는 ＊ 각주로: "지식 증류(Knowledge Distillation)", "소버린AI＊".

## 6. 톤앤매너·강조

- [철칙] 객관·건조 개조식. 감정 수식어 배제 — 강조가 필요하면 "대폭·획기적·극대화" 수준의 한자어를 **수치 근거와 결합해 어필 지점에만** 투입.
- [철칙] **강조 2계층** ('26.7.28 사용자 확정, R040): ① 강조 = **볼드** — ㅇ 항목의 **핵심 명사구만 선별 볼드** (문장 전체 볼드 금지). 볼드 밀도는 문서 격에 비례 — 원장 보고 계획서는 촘촘히, 단신 보고는 절제. ② **특히 강조 = 노란색 음영 하이라이트** — 초안 md `==문구==` 표기(md-profile §1-3), 변환 시 노란 음영+볼드로 재현(260331 실무본 'AI검증 후 최종결과물 변환' 실측 관례). 문서당 극소수 지점에만 사용.
- [철칙] 근거는 문미 괄호로: "(5.19 기관장 지시사항)", 언론 인용은 "※ (전자신문 '25.4.24) 행안부, …". ★·이모지·임의 색 강조는 본문 금지(★는 파일명 전용, 색은 R040 노란 음영 하이라이트만 허용).

## 7. 절 구성·맺음말

- [관례] 전형 흐름: **배경(왜) → 내용·현황(무엇) → 판단(시사점·검토 결과) → 향후계획(다음) → 붙임(근거)**.
- 절 제목 어휘 풀(코퍼스 출현): 추진 배경 / 개 요 / 검토 배경 / 현황 및 문제점 / 그간의 경과 / 주요 내용 / 추진 내용 / 조사결과 / 검토 결과 / 검토 사항 / 개선 방안 / 기대 효과 / 시사점·주요 시사점 / 향후 계획·향후 일정 / 추진 일정.
- [조건] 맺음말 분화:
  - 계획·방안형 → **"□ 향후 계획"** + "ㅇ 할 일(명사구) : 시점" 콜론형 또는 "실시('26.7월)" 문미 괄호 시점형.
  - 조사·동향형 → **"□ 주요 시사점"** 또는 "□ 검토 결과"(판단·건의)로 종결, 향후계획 생략 가능.
  - 결과보고 → "□ 기대 효과 → □ 향후 계획" 이중 마무리 허용.
- [철칙] **의례적 맺음 문구 전무** — "보고를 마칩니다", "적극 추진하겠음" 류 금지. 일정·시사점 나열로 건조하게 끊고 붙임으로 넘어간다.

## 8. 붙임

- [철칙] 붙임 헤더 = **3열 배너 표**: `| 붙임 1 | | 제목 |`. 단수면 `| 붙 임 | | 제목 |`(벌려쓰기). 같은 파일 후속 페이지로 연결.
- [철칙] 배너 표 **제목 셀(3번째) 문단은 양쪽 정렬(JUSTIFY)** — 라벨·스페이서 셀은 가운데 정렬 유지, postprocess `apply_annex_banner`가 배정. 표 자체의 좌측 배치(R035)와는 별개 층위 (R037, '26.7.28 사용자 확정).
- [철칙] 본문↔붙임 분담: **본문 = 요지·판단·요약표**, **붙임 = 전수 데이터·화면 캡처·회의록·서식·출처 목록·상세 비교** (검증용 원자료).
- [철칙] 조사 기반 보고서(검토·계획·동향)는 붙임 「검토 근거 상세」(2p 이내)를 기본 포함한다 — 본문은 두괄식 결정 내용만 담고, 근거의 원문 인용·수치 산출 근거·차용 논리는 붙임으로 배출 ('26.7.24 사용자 확정, R026).
- [관례] 본문 참조는 선택적: "※ 세부내용은 붙임 참조" 또는 "(붙임2 수요조사서)" 괄호 참조, 무참조도 다수. "※ 상세는 붙임N" 정형구를 억지로 넣지 않는다.
- [조건] 대형 집행 문서(RFP 등)는 '기안 본문=결재용 요약, 붙임=집행용 완결 문서' 분담. 붙임 내부는 별지/별첨/붙임 위계.

## 9. 표

- [철칙] 표 다용 — 34건 전부 표 사용. 구성도·프로세스·개념도까지 **도형 대신 표로 구현**(→ `diagram-pool.md`, `table-pool.md`).
- [관례] 캡션 두 계열: **[ 대괄호 ]** = 본문 개념도·집계·비교표 / **< 꺾쇠 >** = 참고·근거 박스. 무캡션(본문 직후 표)도 다수.
- [철칙] 캡션은 hwpx 변환 시 별도 문단이 아니라 **표 `hp:caption`(side=TOP)에 내장**하고 가운데 정렬+볼드(크기 12pt=R023)로 표시한다 — 260331 실무본 실측 원형, postprocess가 자동 내장 (R034, '26.7.28 사용자 확정).
- [철칙] 표 배치는 **우측 정렬**, 붙임·참고 배너 표는 **좌측**, 제목 박스는 가운데 (R015 정정·R035, '26.7.28 사용자 확정).
- [철칙] 첫 열 헤더 "구 분" 벌려쓰기. 셀 안에서도 개조식 유지(∙/- 불릿).
- [관례] 본문 표 2~5열 주류, 붙임 전수 표 6~8열까지. Before/After 비교는 "AS-IS | TO-BE (| 효과)" 구성.
