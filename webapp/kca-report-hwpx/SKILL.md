# kca-report-hwpx — 개조식 보고서 → hwpx (웹앱판)

MCP·작업폴더 없이 동작한다. 중간 파일은 전부 `/tmp`에 두고, 사용자에게는 **최종 hwpx 1개**만
인도한다. 노트북 하네스(report-harness 플러그인)와 **같은 룰·같은 후처리 스크립트**를 쓰지만
문서 생성은 `md2hwpx.py`가 담당한다(하네스는 kordoc MCP를 쓴다).

## 실행 전 준비

```bash
SKILL_DIR="<이 SKILL.md가 있는 디렉토리>"
mkdir -p /tmp/report
```

`references/rules.md`에서 이번 단계 태그(`[draft]` 또는 `[export]`)에 해당하는 항목만 읽어
반영한다. 다른 단계 태그는 이번 실행에 적용하지 않는다.

## ③ 초안작성 — 게이트 최대 3회 (⓪은 답이 명확하면 건너뜀)

### 0단계. 제공자료 적재

사용자가 붙여넣은 자료·첨부는 **파일로 떨어뜨린다** — 나중 팩트체크(경량)가 이 폴더를
근거로 삼는다.

```bash
mkdir -p /tmp/report/research
# 붙여넣은 자료를 /tmp/report/research/{주제슬러그}.md 로 저장 (원출처를 첫 줄에 명시)
```

자료가 없으면 건너뛴다. 다만 **근거 없이 쓰는 상태임을 1줄 고지**하고 진행한다.

### 게이트⓪ — Q&A (4문항 이내)

자료로 답이 이미 명확한 문항은 건너뛰고 남은 것만 묻는다. 선택지형으로 제시한다.

1. **보고서 유형** — 계획 / 검토 / 결과 / 동향. `references/style-guide.md` §0 문서 유형 표에
   매핑된다(맺음말 계열도 여기서 정해진다 — 계획·방안형→"향후 계획", 조사·동향형→"주요 시사점").
   `(권장)`은 요청의 동사에서 정한다 — "비교해줘·조사해줘"면 검토·조사형, "계획 세워줘"면 계획·방안형.
2. **수신자 격·분량** — 원장 보고 / 부서 보고 × 1~3p / 다p.
3. **산출물 요구 — 이 보고서가 반드시 뱉어야 하는 것** (R071, **가장 중요**). 복수 선택 허용.
   ① 판단·결정 ② **수치·산출식** ③ 절차·기준 ④ 현황·동향.
4. **핵심 논지 방향** — 택1 또는 새 방향 입력.

> 3번을 빼면 안 된다. 종전 4문항은 전부 *문서의 형태*만 물었고 *무엇이 나와야 하는가*를 묻지
> 않았다. 그 결과 한 건에서 초안이 여섯 번 반려됐고 실제 요구는 3턴 만에 드러났다.
> **형태를 아무리 정확히 물어도 내용 요구는 안 나온다.**

**기존 문서가 있으면 승계 관계를 함께 확인한다** — 이전 버전·유사 문서를 받았으면 **개정본인가
독립 최종안인가**를 여기서 묻는다. 착수 후에는 되돌리기 가장 비싼 결정이다.

**상황 전제는 자료로 불명확할 때만 묻는다** — 이미 발주·계약한 건인지, 대응할 외부 제기·지적 원문이 있는지, 먼저 받을
상위 계획 문서가 있는지. 착수 뒤 드러나면 논지를 통째로 버리게 된다. 답을 받으면 **보고 설계**(보고 목적·결재자·수신자·
결재자가 내릴 결정·예상 결론·상황 전제 — `references/report-craft.md` §1)를 대화에 한 번 정리해 이후 단계의 기준으로 삼는다.

**구축·운영 과제는 2건을 추가로 확인한다.**

- **실측 데이터 확보 여부** — 운영 실측치가 없으면 `추진 성과` 절(R054)을 세울 수 없다.
  없으면 **정성 서술로 대체됨을 명시**한 채 진행한다(기대 효과로 대체).
- **화면 캡처 제공 여부** — 캡션 후보를 번호와 함께 제시하고 받을지 묻는다. 받지 않으면
  이미지 표를 만들지 않는다. ※ 이 판은 이미지 주입을 지원하지 않으므로(범위 밖) 받더라도
  본문에는 넣지 못한다 — 그 사실을 함께 고지한다.

### 아웃라인 → 게이트①

`10_outline` 상당 내용을 대화에 제시하고 **승인을 받는다.** 승인 전에는 본문을 쓰지 않는다.
반드시 포함할 것:

- 목차 + 절별 논지
- 근거 목록 (확정 / 추정 **태깅**)
- **표 설계** — 어느 절 · 어떤 논지를 지탱 · 열 구성 (`references/table-pool.md` 참고)
- **도식 설계** — `references/diagram-pool.md` 판정표로 패턴을 고르고 **GFM 표로 직접** 그린다
  (이 판은 도식 마커 치환을 지원하지 않는다)
- **설계 점검** — `references/report-craft.md` §2: 제목(결론)·핵심 메시지·근거 구조(서로 겹치지 않게 2~4개)·절별
  So What(절마다 "그래서 무엇인가" 1줄)·구성요소 대조(목적·현황·핵심 메시지·대안·결론·향후계획, 빠지면 사유)·상위 계획 대응

논지 구조가 갈리면 2안을 제시해 고르게 한다.

### 프리플라이트

`references/rules.md`의 `[draft]` 태그 항목을 로드해 집필 지시에 반영한다. `[export]` 항목은
이 단계에 적용하지 않는다.

### 초안 집필

**한 컨텍스트에서 통으로 쓴다** — 절별로 쪼개 쓰면 문체·논지가 갈린다(하네스 금기 2건 중 하나).
`references/md-profile.md`의 허용 문법 **안에서만** 쓴다. 이 서브셋을 벗어나면 변환이 깨진다.

```
□ 1단 — 절 제목 전용
 ㅇ 2단 — 요지 (괄호 리드는 **(한 계)**처럼 볼드 래핑 — R016)
   - 3단 — 상세 (한 ㅇ 아래 2개까지, 중첩 불가)
※ 참조·단서    ＊ 각주 (전각만)
[ 캡션 ]  또는  < 캡션 >
| GFM 표 |   (6열 상한, 셀 병합 없음)
| 붙임 1 | | 제목 |     3열 배너
| 산식 = a × b |         1열 산식 박스
| --- |
```

인라인은 `**볼드**`와 `==특히 강조==` 2종만 허용한다. 이탤릭·취소선·인라인 코드·헤딩·인용·
서술 중 공백-하이픈은 전부 금지다.

첫 줄은 제목, 둘째 줄은 발신 줄 `< '26. 8. 4.(화), 본부 팀 >` 형식으로 쓴다.

작성 직후 린트를 돌리고 **통과할 때까지 고친다**.

```bash
python3 "$SKILL_DIR/scripts/lint_md_profile.py" /tmp/report/draft.md
```

exit 1이면 위반 목록으로 즉시 고쳐 재실행한다 — **통과할 때까지 사용자에게 보이지 않는다.**

### 스타일 자가감사 ∥ humanizer

lint 통과 후 두 가지를 이어서 한다.

**① 자가감사** — `references/style-guide.md`와 `references/rules.md`의 `[draft]` 태그로
직접 대조 점검하고, `references/report-craft.md` §3 흔한 실수 점검표(사실 없는 상상·실행 없는 의미 부여·진부한 답·
불리한 사실 감추기·날짜·단위 불일치·욱여넣기)를 1회 본다. 둘이 부딪히면 style-guide가 이긴다. 자주 걸리는 항목:

- 한 ㅇ 아래 대시 3개 이상(R045) → 성격이 가까운 것끼리 한 서술로 통합하거나 ㅇ를 둘로 쪼갠다
- 문장 전체 볼드 → 핵심 명사구만 선별
- 수치 변화는 항목명 뒤 괄호에 담기(R065) — 괄호는 변환 시 13pt로 축소된다

**② humanizer 윤문** — `references/humanizer/HUMANIZER.md`를 읽고 그 절차대로 AI 문체 흔적을
걷어낸다(쉼표 과다·번역투·대명사/복수형 남용·구조적 단조로움 등 40패턴, S1/S2/S3 심각도).
세부 패턴은 `references/humanizer/references/`에, 전후 예시는
`references/humanizer/examples/`에 있다.

- **서술형 구간에만 적용**한다 — 배경 설명·근거 서술 등. **개조식 명사형 종결부는 대상에서
  제외**한다(`~함`·`~임`으로 끝나는 항목을 문장으로 풀면 개조식이 무너진다).
- 적용 전후로 **수치·인용이 불변인지 확인**한다. 하나라도 달라졌으면 그 절만 되돌리고 다시 한다.
- 윤문 후 lint를 **다시** 돌린다 — 문장을 손대면 md-profile 위반이 새로 생길 수 있다.

> humanizer는 서드파티 번들이다(DaleSeo, MIT). 고지는 `NOTICE.md` 참조.

### 게이트② 초안 승인

초안 전문을 대화에 제시한다. **모든 절·항목에 절 주소 ID**(`□3`, `□3-ㅇ2`)를 붙여 한 줄
지시로 피드백받을 수 있게 한다. 선택지는 셋이다.

1. **전체 승인 + 팩트체크** — 경량(기본) / 생략 중 택1
   ```bash
   python3 "$SKILL_DIR/scripts/validate_hwpx.py" numbers /tmp/report/draft.md /tmp/report/research
   ```
   `numbers-unsourced`로 걸린 수치는 출처를 확인해 고치거나 `[추정]`으로 태깅한다.
   생략하면 **미검증 사실이 남을 수 있음을 인도 시 1줄 고지**한다.
2. **지정 절 수정** — 절 주소 ID로 지목된 절만 고친다. **변경 diff만 다시 제시**한다(전체 재제시 금지).
3. **방향 전환** — 게이트①로 되돌아간다.

**수정 왕복이 3회를 넘으면** 아웃라인 자체의 문제로 보고 게이트① 회귀를 제안한다(강제 아님).
승인 후 ④로 넘어간다.

## ④ 변환 — 자동, 게이트 없음

```bash
cd /tmp/report

# 0) 자산 복원 — 바이너리 업로드를 막는 플랫폼(Gemini)에서만 실제로 동작하고,
#    그 외에는 무해한 no-op이다. 항상 먼저 한 번 돌린다.
python3 "$SKILL_DIR/scripts/decode_assets.py"

# 1) 정규화 — 모호한 입력은 exit 2로 거부한다(중단하고 사유·줄번호를 보고)
python3 "$SKILL_DIR/scripts/prep_report_md.py" draft.md -o prepared.md

# 2) 생성
python3 "$SKILL_DIR/scripts/md2hwpx.py" prepared.md -o base.hwpx

# 3) 후처리 — --all이 발신 줄 12pt(R018)까지 기본 적용한다
cp base.hwpx "결과.hwpx"
python3 "$SKILL_DIR/scripts/postprocess_hwpx.py" "결과.hwpx" --all > post.json

# 4) 침묵 실패 차단 + 기하 불변식 — 실패 시 여기서 중단한다
#    hwpx를 3번째 인자로 넘겨야 제목표 상단 여백·열 폭 역전까지 검사한다(빠뜨리지 말 것)
python3 "$SKILL_DIR/scripts/assert_postprocess.py" post.json prepared.md "결과.hwpx"

# 5) 구조 검증
python3 "$SKILL_DIR/scripts/validate_hwpx.py" structural "결과.hwpx"

# 6) 왕복 대조 — python-hwpx가 있으면 그걸 쓰고, 없으면 stdlib 폴백으로 자동 전환된다
python3 "$SKILL_DIR/scripts/roundtrip_md.py" "결과.hwpx" -o roundtrip.md
python3 "$SKILL_DIR/scripts/validate_hwpx.py" compare prepared.md roundtrip.md --hwpx 출력.hwpx
```

### 판정 규칙

- **4단계(assert)가 실패하면 인도하지 않는다.** 실패 목록을 그대로 보고하고 원인을 고친 뒤
  2단계부터 재시도한다. 이 검사는 "룰이 조용히 무효화된 상태로 통과"하는 사고를 막는 유일한
  방어선이다. 특히 `title_box.no_leading_blank`·`table.column_width_inverted`는 구조 검증과
  왕복 대조를 전부 통과하고 **한글로 열어야만 보이는** 결함이라, 여기서 못 잡으면 그대로
  인도된다('26.8.7 실제 재발 사례).
- **6단계 compare의 `count-mismatch:tables`가 `+1`이면 정상이다** — 머리말 배너 1개가 정상 가산된
  것이다(제목 박스는 1칸 상자라 세지 않는다). 그 외 항목 불일치나 `markdown-leftover`·`literal-markup`은
  실패로 본다.
- 2회 재시도 후에도 불일치가 남으면 **조용한 변환 손실을 만들지 않는다** — 잔존 목록을 명시
  보고하고 `draft.md`를 그대로 인도한다. hwpx 실패가 md 인도를 막지 않는다.
