하네스가 정상 동작할 수 있는 상태인지 점검한다. **첫 실행 전이나 결과가 이상할 때** 쓴다.

## 1. 환경 진단 (스크립트)

```
python3 skills/report-pipeline/scripts/doctor.py
```

종료 코드 — `0` 이상 없음 / `1` 경고(동작은 함) / `2` 치명(파이프라인 불가).

출력의 `✗` 항목을 먼저 해결한다. 조치 문구가 함께 나온다.

## 2. kordoc MCP 연결 확인 (모델이 수행)

스크립트는 MCP를 호출할 수 없으므로 **이 단계는 직접 확인한다.**

`mcp__kordoc__parse_document`를 이 저장소의 아무 md 파일에 시험 호출해 응답이 오는지 본다.
도구가 목록에 없거나 호출이 실패하면 kordoc이 연결되지 않은 것이다.

**미연결 시 증상** — 파이프라인이 ③ draft까지는 정상 동작하고 **④ export에서 hwpx 없이
md만 남는다.** 처음 쓰는 사람은 이걸 실패로 인지하지 못하므로 반드시 여기서 잡는다.

**복구** — 터미널에서 `npx -y kordoc mcp`를 직접 실행해 오류를 확인한다. 네트워크 차단이나
Node 버전 문제가 대부분이다. 복구 후 `"hwpx로 변환해줘"`로 ④단계만 재실행하면 된다.

## 3. 결과 보고

점검 결과를 **표 한 개**로 보고한다 — 항목 / 상태 / 조치. 이상이 없으면 한 줄로
"이상 없음, 첫 보고서를 시작할 수 있다"로 끝낸다. 정상 항목을 장황히 나열하지 않는다.

치명 항목이 있으면 **그것만** 설명하고 나머지는 생략한다. 조치가 사용자 환경에 달린
것(Node 설치 등)이면 명령을 그대로 제시한다.
