왼쪽에서 판단(references)과 실행(scripts)이 갈라져 있고, 웹앱 배포판은 따로 선다. 오른쪽은 건마다 하나씩 생기는 폴더다 — 조사부터 되읽기 검증까지 전부 파일로 남아 "이 숫자 어디서 나왔냐"에 폴더를 열어 답한다.

재사용 — kordoc · korean-law · humanizer · insane-search, 범용은 전부 가져다 썼다. 전부 MIT고, 빌드가 원작자 고지와 상류 바이트 일치를 검사한다. 직접 만든 것은 기관 양식에 붙는 부분뿐이다 — 양식 정합 후처리, 검증 3층, 자립 변환기, 복리축적 규칙.
