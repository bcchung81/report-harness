    Four stages

    단계마다 산출물이 정해져 있다

    단계하는 일산출물기계 시간
    ① research제공자료 적재 · 위키 조회 · 신규조사 research/ + _manifest.jsonl—
    ② analyze조사 결과 종합 05_analysis.md5분
    ③ draft개조식 초안 — 게이트 3개가 전부 여기 10_outline.md → 20_draft.md10분
    ④ export팩트체크 ∥ 회귀검사 → 양식 정합 변환 final/{제목}.hwpx + 40_qa.md5분

    필요한 구간만 골라 진입한다. 자료가 있으면 ②부터, 초안이 있으면 ④만.

    Research: contract, not method

    조사는 방법을 강제하지 않는다

    자유

    어떤 도구로 조사하든 상관없다
    환경에 있는 걸 골라 쓰고, 없으면 건너뛴다

    강제

    산출물이 계약대로 쌓이는 것
    프론트매터 · _manifest.jsonl

    산출물 1건당 manifest 1줄 — 출처 · 시각 · 도구 · 확정/추정. 원문 발췌로 수집하고(의역 금지), 이미 확보한 근거는 다시 조사하지 않는다. 그래서 도구가 하나도 없어도 파이프라인이 멈추지 않는다.

    Getting it to people without terminals

    웹앱판 — 파일 하나로 끝난다

    하네스에서 규칙 축적
    빌드 기준 9종
    .skill / .zip
    VDI 브라우저

    MCP도 플러그인도 없이 전 구간 stdlib으로 돈다. claude.ai · ChatGPT · Gemini 세 곳 모두 지원하고, Gemini판만 바이너리 금지라 배너를 base64로 싣는다. 빌드 기준(룰 최신성 · 드리프트 0 · dangling 0 · 사장 자산 0 · PII 0 …)을 전부 통과해야 패키지가 만들어진다.

    웹앱판은 세션 사이에 아무것도 기억하지 못한다 — 재배포가 복리축적을 실무자에게 전달하는 유일한 경로다.
